---
description: Write a short, honest incident retro after something broke (what happened, root cause, fix, how to prevent it)
---

Write an incident retro for what just went wrong. Keep it factual and short.

1. What happened: timeline in 3-6 lines, with real times and the visible impact (who or what was affected, for how long).
2. Root cause: the actual cause you verified, not a guess. If it is unverified say "probable cause".
3. Fix: what you changed, and how you confirmed it works.
4. Prevention: one concrete check or rule that would have caught it (a command to run before deploy, a test, a line in CLAUDE.md or a skill).
5. Save it next to the project notes and add the prevention step to the project's checklist or a skill.

Do not blame; do not hide the mistake. If part of the cause was the assistant's own shortcut (for example concluding from one keyword search), say so.
