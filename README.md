# t00-claude-kit

Skills, rules and commands for [Claude Code](https://claude.com/claude-code), extracted from a real workspace where one person runs dozens of small projects with an AI assistant. Everything here was written after a real mistake or a repeated chore, and each file says why it exists.

Live products built this way: https://maysunai.wordpress.com/

## How to use

- Skills: copy a folder from `skills/` into `~/.claude/skills/` (all projects) or `<project>/.claude/skills/` (one project). Claude loads a skill when its `description` matches what you ask.
- Rules: plain Markdown. Paste into your `CLAUDE.md` or reference one with `@rules/<file>.md`.
- Commands: copy a file from `commands/` into `.claude/commands/`.

## Growing the kit

1. Put a new skill in `skills/<name>/SKILL.md` with `name`, `description`, `metadata.version`, `metadata.created` in the front matter.
2. Run `python tools/build_index.py` to refresh the catalog.
3. Tag a release (`git tag v0.2.0 && git push --tags`). Keep a CHANGELOG line per release.
4. Group by topic with sub-folders once a folder passes about 20 files.

## Safety

Before publishing anything from a personal workspace, scan for secrets, tokens, e-mail addresses, server IPs and user names. Files that only make sense on one machine stay private.
